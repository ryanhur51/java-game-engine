# Video Game Engine
This Java program is a 2D game engine with Flappy Bird implemented to prove its usability.  

# Gameloop
The gameloop manages both the rendering and updating of the game engine. It uses the nanoTime method to calculate the duration of each frame.  
  More information on gameloops here: https://gameprogrammingpatterns.com/game-loop.html  

# Abstract Window Toolkit
I used Java's awt to develop the window, rendering processes, inputs, and image loading.  
The window required to create a canvas, which is a blank rectangle where graphics can be drawn, a frame, and a buffer straetgy. The buffer strategy allows for smooth graphics by manipulating multiple buffers.  
More information on awt: https://docs.oracle.com/javase/8/docs/api/java/awt/package-summary.html
